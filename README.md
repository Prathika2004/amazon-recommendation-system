# Amazon Electronics Recommendation System

This project implements a **Hybrid Recommendation System** using
collaborative filtering and content-based filtering techniques on the
Amazon Electronics dataset.

## 📌 Features
- Collaborative Filtering (SVD++)
- Content-Based Recommendation
- Hybrid Model Integration
- User–Item Interaction Analysis
- Performance Evaluation & Visualizations
